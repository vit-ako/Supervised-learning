## Теоретические основы: линейная регрессия и регуляризация

### 1. Аналитическое решение задачи регрессии

**Найдите аналитическое решение задачи регрессии, используя векторную форму уравнения.**

Аналитическое (замкнутое) решение линейной регрессии выводится путем минимизации функции потерь MSE (среднеквадратичной ошибки):

**Векторная форма:**

```
w = (XᵀX)⁻¹ Xᵀ y
```

| Символ | Значение |
|:-------|:---------|
| `X` | Матрица признаков |
| `y` | Вектор целевых значений |
| `w` | Вектор весов |

> **Примечание:** Это решение работает, когда матрица `XᵀX` обратима (признаки не идеально скоррелированы).

---

### 2. Влияние L1 и L2 регуляризации на решение

**Что меняется в решении при добавлении регуляризации L1 и L2 в функцию потерь?**

К функции потерь просто добавляется слагаемое, зависящее от параметров модели.

#### Сравнение типов регуляризации

| Тип регуляризации | Штрафной член | Эффект |
|:------------------|:--------------|:-------|
| **L2 (Ridge)** | `α Σ wᵢ²` | Уменьшает веса (редко до нуля) |
| **L1 (Lasso)** | `α Σ \|wᵢ\|` | Обнуляет веса → **отбор признаков** |
| **ElasticNet** | `α [ρ Σ \|wᵢ\| + (1-ρ) Σ wᵢ²]` | Комбинирует оба подхода |

> 💡 **Ключевая идея:** Регуляризация создает баланс между точностью на обучающих данных и маленькими весами, что предотвращает переобучение.

---

### 3. Почему L1 используется для отбора признаков?

**Объясните, почему для выбора признаков часто используется регуляризация L1. Почему после обучения модели многие весовые коэффициенты равны 0?**

L1-регуляризация не просто штрафует большие веса (как L2), а вводит **линейный штраф** за абсолютное значение каждого веса. Этот механизм заставляет модель "выбирать":

- ✅ **Признак остается** → если он вносит достаточно большой вклад в прогноз, чтобы оправдать свой штраф
- ❌ **Признак удаляется** → если вклад слишком мал, вес становится точно равен нулю

#### Почему L1 дает разреженные решения

| L2 (Ridge) | L1 (Lasso) |
|:-----------|:-----------|
| Штраф квадратичный | Штраф линейный |
| Градиент стремится к нулю при весе → 0 | Постоянный градиент обнуляет веса |
| Веса становятся очень маленькими, но редко нулевыми | Многие веса становятся **точно нулевыми** |

**Результат:** Неважные признаки получают нулевые коэффициенты — это и есть **автоматический отбор признаков**, встроенный в модель.

---

### 4. Моделирование нелинейных зависимостей линейными моделями

**Объясните, как можно использовать одни и те же модели (линейную регрессию, гребневую регрессию и т. д.), но при этом получать возможность подбирать нелинейные зависимости.**

Вместо изменения самой модели мы преобразуем **пространство признаков**:

```
Исходные признаки:   x₁, x₂, ..., xₙ
           ↓
Новые признаки:      z₁, z₂, ..., zₘ  (содержат нелинейности)
           ↓
Линейная модель:     y = w₀ + w₁·z₁ + ... + wₘ·zₘ
```

#### Примеры нелинейных преобразований

| Тип | Формула | Применение |
|:----|:--------|:-----------|
| Полиномиальные | `x²`, `x³`, `x₁·x₂` | Кривизна, взаимодействия |
| Тригонометрические | `sin(x)`, `cos(x)` | Периодические паттерны |
| Экспоненциальные | `exp(x)` | Быстрый рост/убывание |
| Логарифмические | `log(x)` | Убывающая отдача |
| Квадратный корень | `√x` | Замедление роста |

> 🎯 **Ключевой вывод:** Линейная модель, примененная к *нелинейным признакам*, становится нелинейной моделью в исходном пространстве признаков. Это основная идея **полиномиальной регрессии** и **расширения базисными функциями**.

## 🛠 Ход работы и реализация

### 1. Подготовка датасета

- **Данные:** объявления об аренде жилья (цена — целевая переменная)
- **Удаление выбросов** по цене (1–99 перцентили)
- Извлечение **топ-20 удобств** (`features`) и создание бинарных признаков
- Формирование матрицы признаков `X` и целевой переменной `y`

### 2. Реализация модели с нуля

Создан класс `DeterministicLinearRegression`, поддерживающий:

- аналитическое решение;
- градиентный спуск;
- стохастический градиентный спуск;
- L1, L2 и ElasticNet регуляризацию.

### 3. Собственная нормализация

- `MyMinMaxScaler`
- `MyStandardScaler`

> 💡 **Ключевая идея:** Нормализация необходима, когда признаки имеют разные масштабы (например, площадь vs. количество комнат), но не влияет на деревья решений.

### 4. Полиномиальные признаки

Я вручную добавила квадраты признаков, чтобы линейная модель могла улавливать нелинейные эффекты.

### 5. Метрики оценки

- **MAE** (средняя абсолютная ошибка)
- **RMSE** (среднеквадратичная ошибка)
- **R²** (коэффициент детерминации)

**Сравнение включало:**
- мои модели vs. стандартные реализации `sklearn`;
- наивные модели (среднее / медиана как baseline).
